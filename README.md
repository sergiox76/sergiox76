## Proyectos

### 🐝 SAGGIO — Plataforma web de intercambio de conocimiento con IA
> Sistema de Apoyo a la Gestión y Generación de Información y Objetos de Conocimiento.

Plataforma colaborativa para estudiantes universitarios: repositorio de apuntes, asistente académico con IA conectado al contenido que suben los propios estudiantes, generación de talleres y simulacros de práctica, foros y analítica de progreso.

- Arquitectura modular (7 módulos) desarrollada con metodología SCRUM
- MVP con módulos completos de autenticación, contenido académico y asistente de IA
- Asistente basado en información verificada (los apuntes de la plataforma), no en respuestas genéricas
- Versión de validación desplegada y usada en investigación de usuarios (encuesta NPS + entrevistas)
- Presentado en RREDSI (Red Regional de Semilleros de Investigación)

**Stack:** Python · FastAPI · Ollama · Anthropic API · Vercel
🔗 [github.com/sergiox76/Saggio_MVP](https://github.com/sergiox76/Saggio_MVP) · 🌐 [saggio-mvp.vercel.app](https://saggio-mvp.vercel.app)

### 💬 DataDialogue AI
> Consulta bases de datos en lenguaje natural, sin escribir SQL.

- Traduce preguntas en español a consultas SQL sobre una base de datos bancaria
- Modelo de lenguaje local (Ollama, llama3.2) orquestado con LangChain: sin costos de API y con los datos en local
- Respuestas por voz con ElevenLabs (text-to-speech)
- Reduce la barrera técnica para que equipos no especializados analicen datos

**Stack:** Python · LangChain · Ollama · Streamlit · PostgreSQL / SQLite · ElevenLabs
🔗 [github.com/sergiox76/datadialogue-ai](https://github.com/sergiox76/datadialogue-ai)

### 🔐 Diffie-Hellman interactivo
> Implementación del intercambio de claves Diffie-Hellman con visualización paso a paso.

- Frontend interactivo que muestra cada etapa del intercambio
